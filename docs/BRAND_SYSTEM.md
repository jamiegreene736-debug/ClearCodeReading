# ClearCode Brand System

The March 2026 brand kit is the visual authority for public marketing, assessment,
authenticated portal, email, and native application surfaces.

## Identity

- Name: **ClearCode Reading**
- Tagline: **Unlock Reading. Unlock Everything.**
- Primary mark: channeled-C lockup
- Compact mark: channeled-C monogram
- Primary typeface: Barlow Condensed

Do not restore the retired illustrated-book logo, insert a space between “Clear” and
“Code” in the brand name, recolor supplied marks, or place a mark directly over a busy
image.

## Tokens

| Token | Hex | Use |
| --- | --- | --- |
| Ink | `#0F2B35` | Primary text and dark surfaces |
| Forest Teal | `#2C4A45` | Headings and secondary actions |
| Deep Teal | `#1A7A7A` | Interactive controls and links |
| Medium Teal | `#2EB8B8` | Digital accent on dark surfaces |
| Eucalyptus | `#5A9E8F` | Secondary data and inner channel |
| Seafoam | `#A8CFC4` | Supporting surfaces |
| Sand | `#E8D5B0` | Warm supporting surfaces |
| Linen | `#F7F2EA` | Default light background |
| Gold | `#F5A623` | Milestones and flagship moments |

Use white only where a clean content surface needs more contrast than Linen. Gold is
not a general-purpose light-background fill.

## Runtime assets

Web runtime assets live in `marketing-website/assets/logo/`. The complete supplied PNG
set is retained under `marketing-website/assets/logo/brand-kit/`; cropped `*-ui.png`
lockups remove only unused canvas space.
